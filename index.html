## How It Works ContentKeeper (installed via MDM) blocks `youtube.com` and `*.youtube.com` at the device level. The key loophole: **`youtube-nocookie.com` is a *separate registered domain***, not a subdomain of `youtube.com`. If ContentKeeper's blocklist uses `youtube.com` + `*.youtube.com`, the `youtube-nocookie.com` embed slips through. Your GitHub Pages site (`yourname.github.io`) acts as the "host page" — the browser navigates to *your* domain, and the video loads in an iframe from the non-blocked domain. --- ## Project Setup Create a new GitHub repo (e.g., `yt-bypass`), then add this single file: ### `index.html` ```html 📺 Stream
